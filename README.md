# 💬 WhatsApp Clone (Flutter + Dart)

A fully functional **WhatsApp UI clone** built with **Flutter** & **Dart** 🚀  
Includes **Chats 💬, Status 📸, Calls 📞, Dark Mode 🌙, and Search 🔍**.

---

## ⚡ Features
- 📱 WhatsApp-like UI with **Chats, Status, and Calls tabs**
- 🌓 **Light & Dark Mode toggle** using Provider
- 🔍 **Search chats** by name or last message
- ✅ **Read & Delivered indicators** for messages
- 🎨 Custom theming and reusable widgets

---

## 🛠 Tech Stack
- [Flutter](https://flutter.dev/)
- [Dart](https://dart.dev/)
- [Provider](https://pub.dev/packages/provider) (for state management)
- [intl](https://pub.dev/packages/intl) (for date & time formatting)
